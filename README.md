# T380 BET — demonstração

Plataforma responsiva de máquinas caça-níqueis fictícias, criada como projeto independente.

## Executar
Abra `index.html` em um navegador ou publique com GitHub Pages.

## Publicar no GitHub Pages
1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**; salve.
4. Aguarde a publicação. O endereço esperado é https://arruda-barber.github.io/T380.bet/

## Escopo
- Jogos originais de demonstração, com resultados aleatórios locais.
- Saldo inicial de 10.000 créditos fictícios.
- Histórico e estatísticas salvos apenas no navegador do aparelho.
- Nenhuma conta real, servidor, pagamento, depósito, saque ou prêmio resgatável.

Este projeto não implementa apostas com dinheiro real. Qualquer eventual produto de jogo com valor monetário exige análise jurídica e regulatória e as autorizações aplicáveis antes de qualquer operação.
